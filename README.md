<h2>Description</h2>  

GoPhish! is a Google Chrome Extension aimed to give users a safer browsing experience by analyzing suspicious links primarily found in email. The extension's primary targets are popular web browser email services like Gmail and Outlook, but it also works on any link on the internet, accessed through the right-click context menu.

When a user clicks on a link, they are sent to a GoPhish! webpage that displays the safety verdict of the link via URLScan.io's scan results of the link. The page displays a live screenshot of the link at the time it was clicked and scanned, summarized details of the link such as the domain name and IP address, and recommendations to spot phishing and staying safe online. 


<h2>Getting Started</h2>  

<h3>Installing</h3>
<li>The extension can be downloaded for free from the <a href="https://chromewebstore.google.com/detail/ingfhkanmpbloalihcbmpcbhipnleooe?utm_source=item-share-cb">Chrome Web Store.</a>
<li>To download, click Add to Chrome and click Continue to Install and Add extension if pop ups appear.</li>


<h3>Set Up</h3>
<li>To check if the extension has properly been installed, click on the puzzle piece icon in the top right of your Chrome window.</li>
<li>From there it will open up the Extensions menu. Go to the very bottom and click on Manage Extensions.</li>
<li>In the bigger Extensions menu, scroll down if needed until you see GoPhish!. If the extension is not already enabled, enable it by clicking on the slider button, which will be blue if the extension is enabled and active.</li>

<h3>Use</h3>
<h4>Clicking Email Links</h4>
<p>GoPhish! will automatically redirect any link when the user left-clicks on any link in their email inbox.</p>
<p>If the user does not want an email link to be redirected, hover over the link and right-click it. Find GoPhish! in the context menu, hover over it, and there should be an Open Link option that takes the user straight to the link.</p>

<h4>Everyday Browsing</h4>
<p>GoPhish! can be used for everyday browsing on any link on the internet. Hover over any link and right-click it. Select GoPhish! from the drop down menu. </p>
