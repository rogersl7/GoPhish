Privacy Policy

GoPhish! does not collect any personal information from users. Our extension uses a backend hosted on Vercel to process API requests and communicates with urlscan.io to perform URL scans. No user data is stored on our servers. All sensitive information, such as API keys, is stored securely on the backend and is never exposed to users. For more information about the privacy practices of third-party services we use, see: Vercel: urlscan.io: https://urlscan.io/about/privacy/ If you have additional questions about this privacy policy, please contact GoPhishUC@gmail.com.
